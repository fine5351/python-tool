# Python Tool Suite

個人自用 Python 工具集與自動化專案集合。各專案獨立維護於個別專屬分支中：

## 專案分支索引 (Branch Index)

- [**feature/video-editor**](../../tree/feature/video-editor)：以 AI 多模態與 FFmpeg 輔助的長篇遊戲劇情影片智慧剪輯與無損分割工具。
- [**feature/rpa**](../../tree/feature/rpa)：多平台（YouTube, Bilibili, 小紅書, TikTok）自動發佈與 Gemini 視覺游標自動化系統。
- [**feature/game-assistant**](../../tree/feature/game-assistant)：基於 TypeSafe Jev 與 Gemini 視覺的即時遊戲語音輔助助手。
